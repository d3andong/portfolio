Context

Problem.

Problem
Company knowledge is scattered across PDFs, wikis, and Notion.
New hires ask the same questions repeatedly in Slack. Managers answer them repeatedly. The information exists; retrieval is the bottleneck.
Users
Admins who own the corpus, new hires who need answers.
Admins upload and curate. New hires need fast, specific, verifiable answers.
Constraint
Answers must cite their source.
Generic LLMs hallucinate. HR-grade answers require a traceable link back to the document and section.
Approach
RAG with inline citations and a source-card UI.
Retrieval-augmented generation over ChromaDB. Every claim is tagged with a source number; every source card links to the original document.

Architecture

Stack.

Vite + React frontend. FastAPI backend with four routers under /api. ChromaDB persists one collection per topic. OpenAI text-embedding-3-small for vectors, gpt-4o-mini for generation.

Chunking splits on paragraph → sentence → word boundaries with 50-character overlap and header detection. Retrieval returns top-5 chunks filtered at cosine ≥ 0.3. The generator prompt restricts the LLM to retrieved context and requires inline source tags.

GET /api/topics POST /api/query /api/documents /api/viewer
Design decisions

Three product calls.

Pre-load real corpora. An empty RAG demo doesn't demonstrate retrieval. Three indexed knowledge bases (GitLab, SBA, Supabase) let a visitor test the loop immediately.

Collapse sources by default. The answer is primary; citations sit below, collapsed. Users who trust the answer move on. Users who need verification expand.

Display chunks verbatim. Retrieval sometimes returns fragments with markdown or hashes. The source card shows them as-is so users can diagnose why an answer was produced.

Generator system prompt (excerpt)
You are OnboardAI, an assistant grounded in the retrieved context below.
Rules:
→ Answer only using the provided context.
→ Cite every claim inline as Source N.
→ If the context does not contain the answer, say so plainly.
→ Preserve numbered lists, links, and structure from the source.
// Retrieved chunks: top-5, filtered to cosine ≥ 0.3
// Conversation history: last 5 turns
